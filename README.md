# Sentinel – Visual Prototype

## Overview

Sentinel is an AI-powered Multi-Modal Authenticity & Threat Verification System designed to detect AI-generated financial scams and verify the authenticity of financial communications across multiple channels, including:

- Video
- Voice Calls
- Emails
- Text / Social Media

This repository contains the **visual prototype (frontend only)** developed for the SEBI Securities Market Hackathon. The prototype demonstrates the intended user experience, workflow, and interface of the final system.

---

## Purpose

The objective of this prototype is to provide judges with a clear visualization of how Sentinel would function from a user's perspective.

It showcases:

- User interface design
- System workflow
- Navigation between modules
- Detection results presentation
- Explainable AI outputs
- Risk assessment dashboard

> **Note:** This prototype is intended solely for demonstration purposes and does **not** perform actual AI inference, deepfake detection, phishing detection, or fact verification.

---

## Proposed Workflow

1. User uploads a communication (Video, Voice, Email, or Text).
2. System processes the selected input.
3. Layer 1 performs Content Authenticity Verification.
4. Layer 2 performs Information Authenticity Verification.
5. Fusion Engine combines both analyses.
6. Final explainable verdict is displayed:
   - ✅ Verified
   - ⚠️ Suspicious
   - ❌ High-Risk
